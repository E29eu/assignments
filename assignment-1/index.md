# Learning Assignment

Publish a simple web page with GitHub and Markdown. You need only a web browser and a free GitHub account. We test how you learn a tool you may not know yet, so take the time to read the guides.

**Resources:**

- Markdown guide: [Basic writing and formatting syntax](https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax)
- GitHub Pages guide: [Quickstart for GitHub Pages](https://docs.github.com/en/pages/quickstart)
- Pull request guide: [Creating a pull request](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/proposing-changes-to-your-work-with-pull-requests/creating-a-pull-request)

**Assignment:**

1. Create a free account on [github.com](https://github.com/signup) (skip if you already have one).
2. Create a new repository named **[your-full-name]-e29-assignment** and make it **Public**.
3. In your repository, create a file named **index.md** that contains:
   - a title (heading level 1) and at least two section headings (level 2)
   - a short paragraph
   - one bulleted list and one numbered list
   - bold and italic text
   - a link to <https://e29.eu>
   - one image from public domain (CC0 license, e.g. from <https://www.flickr.com/commons>) that you upload to the repository and show on the page
4. Publish the page with GitHub Pages: **Settings > Pages > Deploy from a branch > main / (root)**. After a few minutes your page is live at `https://<your-username>.github.io/e29-assignment/`.
5. Add to the page a table through a pull request: create a new branch, add a line "Last updated: `<date>`" to index.md, open a pull request and merge it. Check that the live page shows the change.

**Please send us:**

- the link to your repository
- the link to your live page
